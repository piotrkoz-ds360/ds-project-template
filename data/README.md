# Dane

Dane nie trafiają do repozytorium. W Gicie zostaje tylko struktura
katalogów i ten opis, a same pliki są przechowywane lokalnie.

- `raw/`: dane źródłowe w postaci pobranej, nigdy nieedytowane.
- `processed/`: dane po przetworzeniu, odtwarzalne kodem z `src/`
  lub notatników.
